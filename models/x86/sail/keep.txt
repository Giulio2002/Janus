# Opcodes whose dispatch arms are kept by slice.py. Format: `one|two HEX[-HEX]`.
# Every other arm becomes x86_model_error("janus-excluded: ...").
#
# The slice keeps EVERY arm of the one-byte and two-byte maps. Janus' decoder accepts SSE, SSE2,
# SSE3, SSSE3, SSE4, x87 and system opcodes across both maps, and the model itself says what it
# does not implement ("Opcode Unimplemented in x86isa!" / "Translation error ... not translated");
# a Janus-decodable opcode must therefore never be answered with a slicing artefact. Dropping an
# arm saves nothing that matters: an unimplemented arm is a few lines of Lean. (Previously the
# list was exactly Janus' subset, which turned every SSE/x87 case into
# "janus decodes, the slice excludes it".) VEX/EVEX stay stubbed (slice.py): the model
# implements no VEX or EVEX instruction, its maps are 4 MB of `x86_model_error`/`x86_fault`.
one 00-FF
two 00-FF

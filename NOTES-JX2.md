## KEY LESSONS
1. Site wrapper `@[reducible] def xSite (rt) (H) (s_c)` must take the contract parameters as ARGUMENTS and the conjunct uses the BOUND variables of nonvacuous (not file constants like rtW/H0/PW). The pre must be ONE conjunct (wrapper). Premise families (Morestack, Gopanic, Deferreturn): conjuncts are the premises themselves (`pc = addr`, `DeferreturnPre P s`), no wrapper.
2. `StackGuardOK` is a structure: a state change `{s with pc := x}` needs a helper that destructures it (xxx_pc lemmas in jx2_se/ct/cl). Stock `wstate`/`sstate` proofs from Janus/Contracts/*Sat*.lean are reusable; amd stock macros `inp`/`dst` are not visible: inline their simp bodies.
3. Returns conjunct = the main post at the witness's concrete values and BOUND names (runconj_auto in jx2gen.py; `subs` renames constants like PW->P implW->impl). For GoReturns posts copy the file's `returns` statement with subs.
4. Morestack: sm = state at the stub (pc = Extracted.stubs.head!.addr), LR := Extracted.entry (glue), X3 := ret; chain proof through FT record at entry (spdelta 0) then ret stop frame. amd: glue at [RSP], caller ret at [RSP+8].

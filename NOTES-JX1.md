## Recipe (what works; scripts/jx1gen.py + jx1_arm_map1.py, jx1_arm_map2.py, jx1_amd.py)
1. Per contract: `@[reducible] def XSite (M ...) (f) (s_c) : Prop := <the Summary's pre at s_c>` (ONE conjunct; the audit matches the whole pre against one conjunct, flattening would split it).
2. State `wsCall := { mstate mmem (args ..) with pc := BitVec.ofNat 64 <contract addr> }` (amd64: `mstate64 mmem64 ... with rip := ..`), reusing the STOCK witness states of Janus/Contracts/Map*Sat*.lean (their `*_satisfiable` proofs give the pre components verbatim). Helper `rtpre_pc` (RTPre does not depend on pc; destructure StackGuardOK as ⟨g1,g2,g3⟩) transports `mstate_rtpre`; `{s with pc := ..}` is NOT defeq-transparent to the elaborator otherwise. For the example's own mem0-style files (Insert, Lookup, Delete, ClearMap, NewMap, InsertGet) build wsCall like s0 with sp := wsp - frame and prove RTPre by the callerOK recipe (4 groups: Env, guard, CallOK 7x decide, Outside via simp only [..priv.., outside_cons..]).
3. Conjunct: `(∃ (f : T) (s_c : State), s_c.pc = BitVec.ofNat 64 (Extracted.program.contractAddr "runtime.xxx") ∧ XSite M f s_c)` (bare Summary: no f); proof `⟨AMap.empty, wsCall, rfl, wsCall_pre⟩` (rfl works when the file has `def cAddr := contractAddr ..`; with `local macro cA` use `by simp only [wsCall]; exact addr.symm ▸ rfl` (arm64) / `by show BitVec.ofNat 64 cA = _; rw [addr]` (amd64)).
4. Returns conjunct: the run conjunct's POST must be written in the witness's BOUND variables exactly like the main statement's post (e.g. `(f p).getD 0`, not the folded `0`), else "main theorem is not exhibited as a RUN". gen: if the nonvacuous binds m/f/.. use jx1_arm_map2.auto_post (copies correctness's post), else derive from the file's `returns` statement with substitutions. The proof term is `correctness ...` (or `returns` when its statement is already the conjunct); the `returns` theorem is moved before nonvacuous.
5. Pitfalls: `Ready64` is `Contracts.Ready64` in amd64 files; amd64 State must be spelled `Janus.Amd64.State`; no `(x : T) k` ascriptions in the conjunct (use `emp`-style closed defs or bound vars); struct update `{ s0 with ... }` with several fields hit a parse error, build the state with explicit fields instead.
